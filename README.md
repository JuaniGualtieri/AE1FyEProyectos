# Clinical — Portal de pacientes

Primera instancia del proyecto Clinical descripto en el trabajo de Formulación y Evaluación de Proyectos. El alcance se limita al portal de pacientes: profesionales, especialidades, horarios, recordatorios y reserva simulada de turnos.

Todos los datos son ficticios. Este prototipo es académico y no está preparado para almacenar información clínica ni para uso profesional.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
```
